# Лабораторна робота: Калина, AES та CCM

Програма має чотири розділи: покрокова Калина, покроковий AES, CCM із Калиною та порівняння швидкості Калини й AES. Інтерфейс українською. Внутрішні тести й допоміжні команди залишено поза головним меню.

## Запуск в Ubuntu WSL

Із Windows спочатку відкрийте `build-wsl.cmd` у папці проєкту, потім `run-wsl.cmd`. Або в терміналі Ubuntu перейдіть до папки проєкту та виконайте:

```bash
bash scripts/build.sh
./build/kalyna-lab
```

Для повторної збірки відкрийте `build-wsl.cmd` або виконайте `bash scripts/build.sh` в Ubuntu. Файли в `build/` — програми Linux, а не Windows `.exe`.

## Головне меню

1. **Калина:** вибір шифрування або розшифрування, введення основного ключа й тексту або HEX. Програма показує раундові ключі та матрицю після кожної операції базового шифру. Для звичайного тексту застосовується PKCS#7; блоки обробляються окремо в навчальному ECB.
2. **AES:** такий самий покроковий розбір AES-128/192/256 з матрицею 4×4, прямими та оберненими операціями. Для тестового вектора FIPS 197 виберіть HEX `00112233445566778899AABBCCDDEEFF` і ключ `000102030405060708090A0B0C0D0E0F`.
3. **CCM із Калиною:** навчальні або власні параметри, текст/HEX, покрокові CBC-MAC, лічильник, гамування, тег і перевірка підміни. Для прикладу `Hello world! This is Kalyna CCM.` виберіть навчальні параметри, власний текст і натисніть Enter на запит тексту. Цей режим відображає етапи CCM без окремого довгого розбору раундів Калини.
4. **Швидкість:** показує результати для п'яти варіантів Калини й AES-128/256, а нижче — числові результати еталонної Калини в ECB та CCM.

На запит про паузу введіть `1`, щоб переходити між етапами натисканням Enter і робити скриншоти.

## Реалізація та перевірка

Базова Калина — `Kalyna-reference/`; режим CCM — `lab/kccm.hpp`; покроковий AES — `lab/aes_trace.hpp`; оптимізовані реалізації для вимірювання — `ciphers-speed/`. Кожне покрокове перетворення порівнюється з базовою реалізацією. Контрольні вектори Калини, AES і CCM та негативні перевірки виконує `./build/kalyna-lab test`.

Команда `./build/kalyna-lab compare-speed` запускає той самий пункт порівняння без меню. Результати залежать від комп'ютера.

«Калина» походить із наданого архіву. Відсутні компоненти `ciphers-speed` відновлено з [репозиторію автора](https://github.com/Roman-Oliynykov/ciphers-speed), commit `621bb649b0b808ec08fcf6649eb9903ccbe48ba7`. AES описаний у [FIPS 197](https://csrc.nist.gov/pubs/fips/197/final). Навчальний CCM відповідає профілю KCCM для ДСТУ 7624; його контрольні дані зіставлено з Bouncy Castle. [Документація KCCMBlockCipher](https://downloads.bouncycastle.org/java/docs/bcprov-jdk15to18-javadoc/org/bouncycastle/crypto/modes/KCCMBlockCipher.html).
